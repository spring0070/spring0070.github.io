# 俄羅斯
## 莫斯科(Moscow)
- [Wiki](https://zh.wikipedia.org/wiki/莫斯科 "Wiki"){:target="_blank"} 
- [GoogleEarth](https://earth.google.com/web/search/Moscow "GoogleEarth"){:target="_blank"} 
- 俄羅斯的首都，擁有許多世界著名的景點，包括紅場、克里姆林宮、聖瓦西里大教堂和莫斯科州藝術博物館。

### 紅場(Red Square)
- [Wiki](https://zh.wikipedia.org/wiki/紅場 "Wiki"){:target="_blank"}
- [GoogleEarth](https://earth.google.com/web/search/Red+Square+Moscow/@55.7539303,37.620795,17.5a,1000d,35y,0h,0t,0r/ "GoogleEarth"){:target="_blank"}
- 莫斯科市中心的主要廣場，是俄羅斯最重要的歷史地標之一。紅場周圍有克里姆林宮、聖瓦西里大教堂、列寧墓等重要建築。
{% include custom-nav-links.html src="Russia_Red_Square.png" data="photo" title="photo" %}

### 克里姆林宮(Kremlin)
- [Wiki](https://zh.wikipedia.org/wiki/莫斯科克里姆林宮 "Wiki"){:target="_blank"}
- [GoogleEarth](https://earth.google.com/web/search/Kremlin+Moscow/@55.7519993,37.6177344,17.5a,1000d,35y,0h,0t,0r/ "GoogleEarth"){:target="_blank"}
- 俄羅斯總統的官邸，也是莫斯科最古老的建築群。包含多座教堂、宮殿和博物館，是俄羅斯政治和宗教權力的象徵。
{% include custom-nav-links.html src="Russia_Kremlin.png" data="photo" title="photo" %}

### 聖瓦西里大教堂(St. Basil's Cathedral)
- [Wiki](https://zh.wikipedia.org/wiki/聖瓦西里大教堂 "Wiki"){:target="_blank"}
- [GoogleEarth](https://earth.google.com/web/search/St+Basil+Cathedral/@55.7525371,37.6230818,17.5a,1000d,35y,0h,0t,0r/ "GoogleEarth"){:target="_blank"}
- 建於1555-1561年，是俄羅斯最著名的東正教教堂，以其獨特的彩色洋蔥圓頂聞名於世。
{% include custom-nav-links.html src="Russia_St_Basil_Cathedral.png" data="photo" title="photo" %}

### 莫斯科地鐵(Moscow Metro)
- [Wiki](https://zh.wikipedia.org/wiki/莫斯科地鐵 "Wiki"){:target="_blank"}
- [GoogleEarth](https://earth.google.com/web/search/Moscow+Metro/@55.755826,37.6173,17.5a,5000d,35y,0h,0t,0r/ "GoogleEarth"){:target="_blank"}
- 被稱為"地下宮殿"，以其華麗的裝飾和建築藝術聞名。許多車站都裝飾著大理石、馬賽克和雕塑，是世界上最美麗的地鐵系統之一。
{% include custom-nav-links.html src="Russia_Moscow_Metro.png" data="photo" title="photo" %}

### 特列季亞科夫畫廊(Tretyakov Gallery)
- [Wiki](https://zh.wikipedia.org/wiki/特列季亞科夫畫廊 "Wiki"){:target="_blank"}
- [GoogleEarth](https://earth.google.com/web/search/Tretyakov+Gallery/@55.7415,37.6208,17.5a,1000d,35y,0h,0t,0r/ "GoogleEarth"){:target="_blank"}
- 俄羅斯最重要的藝術博物館之一，收藏了大量俄羅斯藝術家的作品，包括著名的《三勇士》等畫作。
{% include custom-nav-links.html src="Russia_Tretyakov_Gallery.png" data="photo" title="photo" %}

### 莫斯科大學(Moscow State University)
- [Wiki](https://zh.wikipedia.org/wiki/莫斯科國立大學 "Wiki"){:target="_blank"}
- [GoogleEarth](https://earth.google.com/web/search/Moscow+State+University/@55.7039,37.5308,17.5a,2000d,35y,0h,0t,0r/ "GoogleEarth"){:target="_blank"}
- 俄羅斯最古老和最大的大學，主樓是莫斯科七姐妹建築之一，以其宏偉的斯大林式建築風格聞名。
{% include custom-nav-links.html src="Russia_Moscow_University.png" data="photo" title="photo" %}

## 聖彼得堡(Saint Petersburg)
- [Wiki](https://zh.wikipedia.org/wiki/聖彼得堡 "Wiki"){:target="_blank"}
- [GoogleEarth](https://earth.google.com/web/search/Saint+Petersburg/@59.9310584,30.3609096,17.5a,10000d,35y,0h,0t,0r/ "GoogleEarth"){:target="_blank"}
- 俄羅斯第二大城市，被稱為"北方威尼斯"，擁有眾多運河和橋樑，是俄羅斯文化藝術的中心。

### 冬宮（俄語：Зи́мний дворе́ц）
- [Wiki](https://zh.wikipedia.org/zh-tw/%E5%86%AC%E5%AE%AE "Wiki"){:target="_blank"} 
- [GoogleEarth](https://earth.google.com/web/search/%e5%86%ac%e5%ae%ae/@59.94154362,30.31341236,2.29754454a,704.36710548d,35y,-5.46273503h,65.14822949t,0r/ "GoogleEarth"){:target="_blank"} 
- 是俄羅斯聖彼得堡的象徵性建築，始建於1721-1762年（聖彼得堡始建於1703年），屬俄羅斯巴洛克建築。現為艾爾米塔什博物館的一部分，收藏了世界級的藝術品。
{% include custom-nav-links.html src="Russia_Winter_Palace.png" data="photo" title="photo" %}

### 彼得保羅要塞（俄語：Петропа́вловская кре́пость）
- [Wiki](https://zh.wikipedia.org/zh-tw/%E5%BD%BC%E5%BE%97%E4%BF%9D%E7%BD%97%E8%A6%81%E5%A1%9E "Wiki"){:target="_blank"} 
- [GoogleEarth](https://earth.google.com/web/search/%e5%bd%bc%e5%be%97%e5%a0%a1%e8%a6%81%e5%a1%9e/@59.9500019,30.3166718,1.81744464a,497.40403998d,35y,226.31858163h,45t,0r/ "GoogleEarth"){:target="_blank"} 
- 是俄羅斯聖彼得堡一座昔日的城堡，由彼得大帝創建於1703年，由多梅尼科·崔茲尼 (Domenico Trezzini)設計，建於1706至1740年。要塞內有彼得保羅大教堂，是俄羅斯歷代沙皇的安葬地。
{% include custom-nav-links.html src="Russia_Peter_Paul_Fortress.png" data="photo" title="photo" %}

### 夏宮(Peterhof Palace)
- [Wiki](https://zh.wikipedia.org/wiki/彼得夏宮 "Wiki"){:target="_blank"}
- [GoogleEarth](https://earth.google.com/web/search/Peterhof+Palace/@59.8844444,29.9086111,17.5a,5000d,35y,0h,0t,0r/ "GoogleEarth"){:target="_blank"}
- 被稱為"俄羅斯的凡爾賽宮"，以其壯觀的噴泉和花園聞名。建於18世紀，是彼得大帝的夏季行宮。
{% include custom-nav-links.html src="Russia_Peterhof_Palace.png" data="photo" title="photo" %}

### 凱薩琳宮(Catherine Palace)
- [Wiki](https://zh.wikipedia.org/wiki/凱薩琳宮 "Wiki"){:target="_blank"}
- [GoogleEarth](https://earth.google.com/web/search/Catherine+Palace+Pushkin/@59.7161111,30.3955556,17.5a,3000d,35y,0h,0t,0r/ "GoogleEarth"){:target="_blank"}
- 位於普希金市，以其豪華的琥珀廳聞名於世。建於18世紀，是俄羅斯巴洛克建築的傑作。
{% include custom-nav-links.html src="Russia_Catherine_Palace.png" data="photo" title="photo" %}

### 涅瓦大街(Nevsky Prospect)
- [Wiki](https://zh.wikipedia.org/wiki/涅瓦大街 "Wiki"){:target="_blank"}
- [GoogleEarth](https://earth.google.com/web/search/Nevsky+Prospect/@59.9311,30.3609,17.5a,2000d,35y,0h,0t,0r/ "GoogleEarth"){:target="_blank"}
- 聖彼得堡的主要街道，被稱為"俄羅斯的香榭麗舍大街"。街道兩旁有眾多歷史建築、商店和餐廳，是城市的文化中心。
{% include custom-nav-links.html src="Russia_Nevsky_Prospect.png" data="photo" title="photo" %}

### 滴血大教堂(Church of the Savior on Spilled Blood)
- [Wiki](https://zh.wikipedia.org/wiki/滴血大教堂 "Wiki"){:target="_blank"}
- [GoogleEarth](https://earth.google.com/web/search/Church+of+the+Savior+on+Spilled+Blood/@59.9402,30.3289,17.5a,1000d,35y,0h,0t,0r/ "GoogleEarth"){:target="_blank"}
- 建於1883-1907年，以其華麗的馬賽克裝飾和彩色圓頂聞名。教堂內外裝飾著超過7500平方米的馬賽克畫。
{% include custom-nav-links.html src="Russia_Church_Spilled_Blood.png" data="photo" title="photo" %}

## 謝爾蓋聖三一修道院（俄語：Тро́ице-Се́ргиева Ла́вра）：
- [Wiki](https://zh.wikipedia.org/zh-tw/%E8%B0%A2%E5%B0%94%E7%9B%96%E5%9C%A3%E4%B8%89%E4%B8%80%E4%BF%AE%E9%81%93%E9%99%A2 "Wiki"){:target="_blank"}

- 也稱謝爾吉聖三一大修道院、聖三一謝爾蓋大修道院，是俄羅斯東正教教會的精神中心，俄羅斯最重要的寺院之一，也是俄羅斯正教最大的男修道院。位於謝爾吉耶夫鎮，是莫斯科金環的重要景點。
{% include custom-nav-links.html src="Russia_Trinity_Lavra.png" data="photo" title="photo" %}

## 聖歐蒂米奧救世主修道院（俄語：Спа́со-Евфи́миев монасты́рь）：
- [Wiki](https://zh.wikipedia.org/zh-tw/%E8%81%96%E6%AD%90%E8%92%82%E7%B1%B3%E5%A5%A7%E6%95%91%E4%B8%96%E4%B8%BB%E4%BF%AE%E9%81%93%E9%99%A2 "Wiki"){:target="_blank"} 
- [GoogleEarth](https://earth.google.com/web/search/%e8%98%87%e8%8c%b2%e9%81%94%e7%88%be/@56.42385811,40.44178448,115.35819094a,6491.56571165d,35y,-0h,0t,0r/ "GoogleEarth"){:target="_blank"} 
- 是位於俄羅斯城市蘇茲達爾的一座修道院。聖歐蒂米奧修道院修建於14世紀，在16世紀至17世紀變得日益重要。修道院內還有一座監獄，最初用來宗教上的異見者。監獄在蘇聯時期繼續得到使用。現在監獄被用作軍事博物館。聖歐蒂米奧修道院於1992年被列入世界遺產弗拉基米爾和蘇茲達爾的白色古蹟群的一部份。
{% include custom-nav-links.html src="Russia_Spaso_Evfimiev_Monastery.png" data="photo" title="photo" %}

## 貝加爾湖（俄語：озеро Байкал，羅馬化：Ozero Baykal，IPA：[ˈozʲɪrə bɐjˈkaɫ]；布里亞特語：
Байгал нуур，拉丁轉寫：Baygal nuur，蒙古語：Байгал нуур）
- [Wiki](https://zh.wikipedia.org/wiki/%E8%B4%9D%E5%8A%A0%E5%B0%94%E6%B9%96 "Wiki"){:target="_blank"} 
- [GoogleEarth](https://earth.google.com/web/search/%e8%b2%9d%e5%8a%a0%e7%88%be%e6%b9%96/@53.68018251,106.82923929,908.17352557a,705029.86279895d,35y,360h,0t,0r/ "GoogleEarth"){:target="_blank"} 
- 位於俄羅斯西伯利亞伊爾庫茨克州及布里亞特共和國境內，面積約為31,722平方公里，距離蒙古國邊界111公里，是世界上水容量最大的淡水湖，最深近2000公尺。被稱為"西伯利亞的明珠"，擁有獨特的生態系統和清澈的湖水。
