# 文章媒體內容更新指南

> [!IMPORTANT]
> **目前目標文章**：Estonia.md  
> **國家變數 `{國家}`**：Estonia (愛沙尼亞)

本文件定義了更新部落格文章中媒體資源（影片與圖片）的標準流程與需求。

---

## 0. 執行工作流 (Workflow)
1. **研究階段**：取得 `{國家}` 變數，於 YouTube 搜尋符合條件的影片，並使用 AI 工具生成或尋找景點圖片。
2. **編輯階段**：開啟對應的 Markdown 檔案，定位至頂部與各景點區塊。
3. **替換階段**：將空連結或舊連結替換為最新資源。
4. **驗證階段**：檢查影片是否可播放、圖片路徑是否正確。如果真的找不到影片就不要放連結。

---

## 1. 媒體資源更新需求

本工作流包含兩個層級的媒體更新：**國家層級 (頂部)** 與 **景點層級 (內文)**。

### A. 國家層級媒體 (文章頂部)
需尋找並更新以下兩類針對 **整個國家** 的影片連結：
- **YouTube 短版 (精華)**：10 分鐘以內，2 年內熱門影片。
- **YouTube 長版 (紀錄片)**：30 分鐘以上，2 年內熱門影片。

### B. 景點層級媒體 (精選景點區塊)
針對文章內「精選景點推薦」中的 **每一個景點**，皆需備齊以下資源：
1. **景點代表圖片**：
   - 需與景點名稱完全對應。
   - 優先使用 AI 工具 (generate_image) 生成具備 Hero Style 的高品質風景圖。
   - **命名規則**：`{國家}_{景點名稱}.png` (例如：`Tanzania_Serengeti.png`)。
2. **景點關聯影片 (短與長)**：
   - 每個景點下方皆需包含 `[YouTube短版]` 與 `[YouTube長版]`。
   - 優先尋找 **專門介紹該景點** 的影片。
   - 若無特定景點影片，則可使用國家層級的高品質影片作為替代。

### 連結格式

```markdown
- [YouTube長版](影片連結 "YouTube長版"){:target="_blank"}
```

### 圖片與導航標籤
```markdown

```

## 3. 執行建議 (YouTube 搜尋)
- **景點影片搜尋建議**：`{景點名稱} {國家} tour 2025` 或 `{景點名稱} 4K drone`。
- **篩選**：以「觀看次數」排序，確保內容品質與熱度。

## 4. 執行檢核清單 (Checklist)
- [ ] 搜尋並確認 YouTube 短版影片 (< 10 min, < 2 years)
- [ ] 搜尋並確認 YouTube 長版影片 (> 30 min, < 2 years)
- [ ] 為每個精選景點準備對應圖片 (AI 生成或搜尋)
- [ ] 更新文章頂部的影片連結
- [ ] 更新各景點章節的影片連結與圖片路徑
- [ ] 檢查 Markdown 語法是否正確（標題、連結、include 標籤）
